# Wave 2 critic brief (read with ../CRITIC_RUBRIC.md and W2_BAR_AND_FIXTURES.md)

You are an independent, adversarial critic. You did not build these boards. Wave 1 established
that BOW can be designed. Wave 2 asks a harder question: does BOW have an interaction model that
deserves to be called a NEW MEDIUM? Many ideas should die here. Killing is a good outcome when it
is earned.

## For every board

Use the CRITIC_RUBRIC.md format: at most 350 words per board, a one-word verdict for each rubric
line, and no averaging. Then add:

- **THE NEW-MEDIUM TEST.** Name the one behaviour on the board that could only exist in a medium
  of executable systems (state, time, actors, roles, rules, causality, history, models, sources,
  possible futures). Quote or point to it in a screenshot. If there isn't one, say "could exist
  unchanged as a [website / dashboard / game menu / LMS / chat app]" and verdict it PARK or KILL.
- **KINDS OF SYSTEM.** Can a person tell apart:
  - Reality (live);
  - a recorded Moment;
  - a historical state;
  - a persistent BOW World;
  - their own active history;
  - a public fork;
  - a model;
  - a creator system?
  Say how each is told apart: by time, material, words, or not at all.
- **GRAMMAR STATUS.** For each interaction primitive the board uses (e.g. "door named by its
  question", "handover with signature", "pull a value across a rule line"), tag it:
  - VERTICAL-SPECIFIC;
  - RECURRING (seen on 2+ boards);
  - CANON-CANDIDATE.
  Only the founder approves canon; never write FOUNDER-APPROVED.
- **3D / SPECTACLE CHECK.** If the board uses depth, animation or spectacle, does a simpler
  representation (list, table, plain text) carry the same understanding? If it does, the
  spectacle is a cost.
- **COMMERCIAL READ.** One line: does the board's COMMERCIAL LENS hypothesis follow from what the
  board actually does, or is it pasted on?

## Tournament comparison

When you review several boards from the same tournament (e.g. ENTER E1–E4), end with a
tournament section. It should:

- rank the boards on the tournament's own question;
- name the winner and the runner-up, and why;
- name what each loser contributes that the winner should absorb;
- name which boards to KILL outright;
- for ENTER, name the two models to transfer to 1787 and Harrow Medical, and what the transfer
  will test.

## Facts

Check real-world claims against the fixture and, where you can, against sources. The fixture
has "[verify]" items; flag any that look wrong. Today is 29 Sep 2026.

## Repairs

Give an exact, ordered repair list per board, concrete enough for a builder to implement with
no further questions: strings, positions, texture changes. List visual bugs you can see
(overlap, clipping, unreadable text).

Do not edit files. Return your critique as your final message.
