# 02 — Worlds semantic archaeology (W @ a43679f2)

Method: code first, docs second. **[C]** code, **[D]** doc claim. Paths are under W; `NBA/` = `runtime/src/modules/worldOne/`, `HW/` = `runtime/src/client/world/`, `SRV/` = `runtime/src/server/`. Labels: EARNED / RECURRING (within Worlds only) / HYPOTHESIS / REJECTED.

**Ground truth.** W holds three unrelated state models, not one World kernel: (1) NBA World One, a server-owned `WorldState` behind one `LessonModule` reducer with a Commissioner clock; (2) Harbor Lights, browser-local, a chain of five chapter reducers, each an act log replay-checked on load; (3) Foundry, JSON declarations compiled to a numeric-resource engine. Shared semantics are repeated conventions, not shared code (`function canonical` is copied into six Harbor files). The authors agree: "no common event schema, identity model … or reducer is established" (SHARED_SUBSTRATE_PROPOSAL [D]).

## (a) Five Worlds semantics most likely platform-level
1. **Authority is derived, never asserted** (actor, seat, verified capability, audience).
2. **Explicit, guarded, fail-closed time**: a named role moves the clock, stale acts are refused, time will not move over a broken obligation.
3. **Append-only history under pinned rule versions**: refusal, not silent migration; missing facts stay unknown.
4. **Fact-or-unknown reads with source paths**, audience fixed at the seam.
5. **Actual / modeled / unknown with an explicit causal-claim refusal**; Lab as one intervention, withheld when undefined.

## (b) Three most likely vertical-specific
1. **Court**: possessions, closing five, calls, Film.
2. **League-season machinery**: stretches, premium seats and partner arc, lottery, luxury tax, arena days.
3. **Real-NBA identity layer and classroom theatre**: `nbaIdentity`, `presentation.ts`, projector reveal/board/countdown.

## (c) AUTHORITY and TIME, precisely

**Authority [C].** Four layers. *Host:* the runtime authenticates the seat; desks cannot send `teacher:` (`sessionService.ts:328`); `acceptsControls:["hook"]` refuses `restore`, `end` and phase controls (`:2633`). *Reducer:* `teacher:w1.*` only from the teacher seat; the teacher "does not act for an owner"; an owner acts through `franchiseOfSeat`, a world-state map where co-owners share full authority; `leagueRun` clubs refuse owners. *Commissioner:* the closed verb list decides WHEN, never WHO or WHAT. *Capability:* legality is a ledger fact (`paidScoutingFunding`). **Harbor has no authenticated authority.** It is browser-local, and the ADR admits "someone controlling the browser can construct a new internally consistent fictional action history." `actorId` and `authority.basis` (`owner-seat`|`paid-roster-mandate`) are rule labels; a delegated person acts only on a saved mandate, and only when the owner advances a day. **Across institutions** the source institution stays authority; a receipt is a documentary snapshot.

**Time [C].** *NBA:* `state.clock` indexes `state.stops`; only `advance(state, expectStop)` increments it (`commissioner.ts:129`). It runs that stop's closing settlement, opens the next, and delivers due work once (`seasonTwo.ts:417-439`: fires when `dueAt === clock`, records `{at, seq}`, refuses to advance if the source changed). It refuses to advance over an unsupported Court (`:73`). Countdown and `live.open` are theatre and never move the clock (`types.ts:664`). Outcomes are "exactly the same whoever pressed it and whenever" (header). The day within a stop is unknown. Season Two is a new sub-world; the carry is computed once and Season One is never rewritten. *Harbor:* no world clock; each chapter has authored time and `clock.changesOnlyByChoice:true` (`harborWorldTimeResponsibilities.ts:51`). Lateness is recorded when the owner advances past the due day, not by a timer. *Foundry:* host-called `advance(state, steps)`; a due commitment settles or turns `overdue` (`compiler.ts:412-431`). **No product has wall-clock world time; the owner of time is always an explicit actor.**

## (d) Doc-vs-code contradictions and divergences
1. **"Moments seal when later events cannot answer them"** is NBA-only; Harbor seals by owner action, Foundry never.
2. **Foundry "Lab hooks / six Lab questions"** (LAB, WORLD_FOUNDRY [D]): `labQuestion` is display text beside a button that opens `institutionComparison` (`HW/main.ts:873-874`); `engine.compare` is called only from `test/worldFoundry.test.ts:112`.
3. **LAB.md "later recorded decisions replayed unchanged"**: the Harbor Lab UI compares the states *at that decision* and drops later actions (`HW/main.ts:957-966`); unknown beyond the horizon.
4. **"Fork"**: `NBA/fork.ts` is Signing Night (star letters), not a what-if. The brief's "never a second actual history" and "does not claim the job caused a fan, basket, or win" are paraphrases; code strings: `nbaSeasonTwoArenaCourtEpisode.ts:109-111`.
5. **"Commissioner advances time; owners get projections"** is NBA-only; Harbor has no commissioner. NEGOTIATION "only Pine Ridge has multi-turn counters" is Harbor-scoped; NBA has versioned counters (`deals.ts:317`).
6. **Five status vocabularies**: League `Knowledge` (6, `types.ts:764`); Foundry `known|estimate|unknown`; Harbor causal `actual|modeled|unknown`; NBA reads `actual|unknown` or `known|unknown`; trade episode `actual-in-run|modeled|unknown`. "Actual" always means recorded inside the simulation.
7. **Contract drift**: E-main `LessonModule` lacks `acceptsControls` and `viewsShareState`; W added both (D199, D228).
8. **Thesis vs code**: "people should outlast one owner." Code has one save-local person (crew lead) and league-scoped fictional staff; presence is unknown everywhere. Legacy Court segments still run on a "historical catalogue fallback" (`courtWorld.ts:65`).
