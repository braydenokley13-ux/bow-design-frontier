## (a) Vocabulary to DROP for standard terms

- **causal engine** → derivation/lineage engine; reserve "causal" for do-calculus on a structural model.
- **lockstep "without a server"** → deterministic replay of a shared log; "without a compute server".
- **act log** → command log (commands can be refused; events are facts).
- **seal / hash-chained record / verifiable branch** → hash chain; branch whose parent hash verifies. Say "tamper-evident" only with signed heads.
- **`bow://`** → `ref@digest`.
- **leak auditor / seat-scoped knowledge** → reference monitor / per-principal projection (information set).
- **truth grammar** → epistemic status flags (keep the seven names).
- **Court/Film** → replay; live vs constructive.
- **Decision Receipt** → replayable transcript / re-execution proof, unless signing is added.
- **WHAT IF** → keep user-facing; internally "counterfactual branch".

## (b) Three places BOW might add something real

1. **Knowability-at-act ladder** (row 9): replay-derived, third-party-recomputable, three-tier, tied to human-decision attribution. RECOMBINATION. Needs a code digest for the reducer and signed capture of "opened" events, or it is only internally consistent.
2. **Type/gate-level separation of actual, modeled and evidence** (`not-evidence` literal, `assessmentEligible:false`, Lab with no write authority, status required to render). Precedents make provenance optional metadata; BOW makes conflation unrepresentable. POSSIBLY NEW as an application constraint; HYPOTHESIS until a second author cannot bypass it.
3. **Counterfactual replay that must ship its intervention rule and a typed UNKNOWN list** for a non-expert audience. Mechanism is CRN/SCM; the mandatory unknown-list is the only addition. Weakest; RECOMBINATION at best.

## (c) Precedents to study before a protocol (ranked)

1. **Bayou**, Kleppmann move-op log, Matrix event DAG + state resolution v2, Lamport/HLC clocks: ordering and conflicts for a role-validated shared log with late arrivals (Live World's open problem).
2. **Bitemporal modelling** (Snodgrass, SQL:2011, Datomic as-of/with, XTDB): for knowability-at-act and Lab.
3. **Certificate Transparency, Crosby–Wallach, IETF SCITT, W3C VC 2.0, in-toto**: if "proves itself" must hold against strangers.
4. **Temporal/Cadence versioning, Unison, reproducible builds/Nix**: pin the reducer by digest.
5. **HLA IEEE 1516 time management + Time Warp**: conservative vs optimistic time.
6. **IFC (Jif), object-capabilities (E, macaroons), commit-reveal/mental poker**: seat secrets vs a lockstep fold.
7. **Pearl SCM counterfactuals + common random numbers.**
8. **PROV-DM, SDMX OBS_STATUS, HL7 NullFlavor, Admiralty code**: before freezing the status set.
9. **FIPA-ACL/Contract Net; ODRL/REA**: before Foundry negotiation.
10. **OIDC pairwise, OAuth, Open Badges**: before `bow-bridge-2`.
